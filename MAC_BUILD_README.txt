MICROBEE PCG CHARACTER EDITOR — macOS BUILD
=============================================

1. Open Terminal.
2. Type cd followed by a space.
3. Drag this project folder into Terminal and press Return.
4. Run:

   chmod +x build_mac.command
   ./build_mac.command

The finished application will be placed in the dist folder and Finder will
open that folder automatically.

The application is built in windowed mode and will not display a Terminal
console when launched.

If another Mac blocks the unsigned app on first launch, Control-click the app,
choose Open, and then confirm Open.
